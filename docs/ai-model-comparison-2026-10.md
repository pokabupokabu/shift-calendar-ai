## 決まった仕様（2026-10-22 ユーザー決定）

| 項目                 | 決定                                                                                                   |
| -------------------- | ------------------------------------------------------------------------------------------------------ |
| ふだんの解析         | **無料・PROとも `claude-haiku-5-5`**                                                                   |
| 高度なスキャン       | **PROだけ**。`claude-sonnet-5-5` で読む                                                                |
| 高度なスキャンの回数 | ふつうの回数（PROは15回）とは**別に足す**。最大5回、**15日ごとに+3（上限5）**                          |
| 回復の時計           | ふつうの回数と**同じ時計**（使い始めて15日、`src/utils/scanQuota.ts` の `cycleStartedAt`）             |
| 最初の回数           | PROになった時点で**5回（満タン）**                                                                     |
| 使い方               | **両方できる**: 解析の前に「高度なスキャンで読む」を選べる＋結果の画面から「高度なスキャンで読み直す」 |

- 料金の目安（1回）: Haiku 約0.29円、Sonnet 約3.8円。PROで回数を使い切ると、1人あたり月に約9円（Haiku 30回）＋約23円（高度なスキャン 月6回ほど）
- 🔴 無料・PROの両方がふだんHaikuになるので、**Haikuが読めない表で全員分をでっち上げる問題を先に直す**（指示文の「名前が無ければ表全体が本人のもの」の決まり）

### 実装の進め方（2026-10-23 ユーザー決定）

- 指示文は「直した版」（読めない表の一文を足したもの）をそのまま使う。前半・後半の取り違えへの一文は足さない
- 中継サーバーは**今の Worker（`gemini-shift-proxy`）に Anthropic への道を足す**。URL・合言葉・回数制限はそのまま。切り替えが済んだら Gemini の道は閉じる
- アプリ側の Gemini のコードは、実機で Anthropic が動くのを確かめるまで設定1つで戻せるように残し、**リリース前に消す**
- 高度なスキャンの画面は**今は最小限**で作り、見た目の仕上げはグループB（スキャンの流れ）の見直しで Stitch を使って行う
- 高度なスキャンは、解析の前に選んだ場合も読み直しの場合も、**高度なスキャンの回数だけを1回使い、ふつうの回数は減らさない**。AIが解析しなかった失敗（通信できない等）は数えない

### 画面の決定・3回目（2026-10-23 ユーザー決定）

- 選んだ写真の表示領域が大きすぎる → **枠を低くし、3枚が横1列に収まる大きさ**にする。4枚のときは枠の大きさを変えずに写真を小さくする（SEでも写真を選んだあとは金のボタンまで見える）
- 画面下の注記は「…シフトの読み取りにのみ使用されます。」
- チュートリアルの吹き出しは「『スキャンする』を押してね。今回は回数を使わないよ」
- 撮影中に見つけた元からの不具合（PROがふつうの回数を使い切って「スキャンする」を押すと課金画面へ飛ぶ）は、押せない状態にして直した
- 小さな点（写真の正方形の切り抜き・白い写真の境目・注記の折り返し）はグループBで扱う

- 「写真を撮る」は黒である必要が無い → **2つとも白い副ボタンにして横並び**（案A）。「ライブラリから選ぶ」は幅の都合で「ライブラリ」に縮めた。黒いボタンの種類はコードから消した

### C2 の実装（2026-10-26 ユーザー確定）

- ブランチ `feat/ui-onboarding-c2`（`origin/main` = `7d798fa` から。C1 とは別のブランチで、触るファイルは重ならない）。実装の確認ページ https://claude.ai/artifact/WxGbJPGVMFh7pEAd43rhsf
- 光る枠の角丸: 見た目の暗さは `react-native-svg` の `Path`（画面全体から角丸の四角を `evenodd` でくり抜く）で描き、押すのを受け止める4枚の `Blocker` は透明にした。新しい依存は無し
- 「シフト表が手元にない」: `hitSlop` は Web で効かないので、高さ44ptの箱＋同じだけの負の余白にした
- 決めた内容の外で足したこと: 小窓の2つの一文と出口の画面の説明文の改行（言葉の途中で切れていたため。文言は同じ）。完了の吹き出しの「はじめる」を `bluePill` に（主ボタンの決まりのあてはめ）
- 前からある点（直していない）: 小窓の名前の欄の例文「シフト表に書かれている自分の名前」が幅375・393とも途中で切れる
- Web で撮れなかった手順（解析失敗・本人確認・内容の確認・完了）は、案内の状態を書き換えて吹き出しだけを撮った。本物の流れは実機で確かめる

# キャラクター仕様書「はこブー」

シフToカレのマスコット。イラスト制作者・画像生成ツールに渡すための指示書。

- 作成: 2026-10-14
- 状態: **ドラフト（ユーザー確認待ち）**。「要確認」と書いた項目は未決

## 1. ひとことで

**シフト表を抱えて、カレンダーへ届けにいく豚の配達員。**

アプリの役割（写真のシフト表 → カレンダー）をキャラの行動そのものにしている。アプリ名「シフToカレ」の `To`（〜へ届ける）が由来。

## 2. 名前

| 項目     | 内容                                                                                 |
| -------- | ------------------------------------------------------------------------------------ |
| 表記     | **はこブー**（ひらがな＋カタカナ。この表記で固定）                                   |
| 由来     | 「運ぶ（はこぶ）」＋豚の鳴き声「ブー」                                               |
| 使う場所 | **アプリ内とSNS等の紹介のみ**                                                        |
| 使わない | **App Storeのアプリ名・サブタイトル・キーワード欄**。英字表記（Hakobu 等）も作らない |

> 使わない理由: 第9類・第42類（ソフトウェア）に読み「ハコブ」の登録商標（第6751196号・株式会社Hacobu）がある。アプリ内のキャラ名に留め、商品名のようには扱わない（2026-10-14 ユーザー判断）。

## 3. 見た目

### 体型

- **2頭身**。頭と胴がほぼ一体の、丸いおまんじゅう型
- 手足は短い。走るポーズが取れる程度の長さは必要
- **輪郭を丸に近づける**（アプリアイコンで小さくなっても形が潰れないため）

### 豚であることの目印（これが無いと豚に見えない）

1. **正面から見える平たい鼻**（鼻の穴2つ）— 最重要
2. 三角の耳（帽子からはみ出す）
3. くるんと巻いたしっぽ

### 服装（配達員）

- **帽子**: 配達員のキャップ。つばが前向き
- **制服**: 半袖のシャツ、またはベスト
- **かばん・荷物**: 持たせない。持ち物はシフト表だけに絞る

### 持ち物: シフト表

- **紙1枚**を両手で胸の前に抱える
- 表の罫線（格子）が見えて「シフト表」だと分かる程度にする。文字は描かない
- 折り目やしわは無くてよい

## 4. 色

| 部位             | 色                                    | 備考                                                       |
| ---------------- | ------------------------------------- | ---------------------------------------------------------- |
| 体               | ピンク（例: `#F7A8BE`）               | 薄すぎると白い背景に溶ける。**要確認**                     |
| 鼻・耳の内側・頬 | 濃いピンク（例: `#E77A9A`）           |                                                            |
| 帽子・制服       | **ブランドの青**                      | 🔴 **要確認**: `#0066FF` か `#007AFF` か（下の注記を参照） |
| シフト表         | 白 `#FFFFFF`＋罫線は薄いグレー        |                                                            |
| 輪郭線           | 濃い紺（例: `#1A2340`）。黒は使わない | 線は太めで均一                                             |

> 🔴 青の注記: 引き継ぎメモでは基調色を `#0066FF` としているが、**アプリの実装（`src/constants/theme.ts` の `primary`）は `#007AFF`**（iOS標準の青）になっている。キャラの制服とアプリのボタンの青を揃えるなら、どちらかに統一する必要がある。

色数は**5色前後に抑える**（アイコン・アニメーションで扱いやすくするため）。

## 5. 表情（3種）

アプリの状態とセットで使う。

| #   | 表情・ポーズ                                     | 使う画面                                                   | 対応ファイル                         |
| --- | ------------------------------------------------ | ---------------------------------------------------------- | ------------------------------------ |
| ①   | **走る**: 横向き、前のめり、シフト表を抱えている | AIが解析している間                                         | `src/app/analyzing.tsx`              |
| ②   | **届いた！**: 正面、目を細めた笑顔、片手を上げる | カレンダー登録の完了                                       | `src/app/complete.tsx`               |
| ③   | **首かしげ**: 正面、眉を下げ、頭の横に「？」     | 本人特定が曖昧・読み取れない（「要確認」「候補から選ぶ」） | `src/app/user-match-select.tsx` ほか |

- **①は次の工程（アニメーション）の土台になる。** 手足が動かせるよう、腕・脚を体と重ならない位置に描いてもらう
- ③は「失敗」ではなく「一緒に確認しよう」の表情にする。**泣き顔・怒り顔にはしない**（ユーザーを責めているように見えるため）

## 6. アプリアイコンでの使い方

- 構図: **①走るポーズの上半身寄り**、またはシフト表を抱えた正面。背景はブランドの青の単色
- 背景が青になるので、**キャラの制服の青と背景が同化しないよう**、白い縁取りか制服の色を一段濃く・薄くする
- 文字は入れない（アプリ名もキャラ名も）
- 角丸はApple側で自動で付くため、**正方形・角丸なし・透明部分なし**で書き出す

### 判別テスト（納品前に必ず確認）

1. **60px** に縮めても「豚」だと分かる（鼻と耳が見える）
2. **白黒にしても**シルエットで分かる
3. iPhoneのホーム画面に並べて、他のアプリに埋もれない

## 7. やってはいけないこと

| 禁止事項                                       | 理由                                                                           |
| ---------------------------------------------- | ------------------------------------------------------------------------------ |
| 「シフカレ」を連想させる文字・図案             | 登録商標（第6228395号）との混同を避ける                                        |
| 英字の名前ロゴ（Hakobu 等）                    | 登録商標（第6751196号）と外観まで近づくため                                    |
| 実在の配送会社を思わせる制服・色・帽子のマーク | ヤマト運輸・佐川急便・日本郵便などとの混同を避ける。帽子は無地か簡単な記号のみ |
| 既存の有名な豚キャラに似せる                   | 著作権・不正競争の観点                                                         |
| `®` や `™` を付ける                            | 未登録。`®` は虚偽表示になる                                                   |
